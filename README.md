# VAST 2021 MC2 可视化分析系统
本项目基于 Python Dash 构建的交互式可视化分析平台，致力于完成 VAST 2021 Mini-Challenge 2。

## 项目介绍
本项目针对 GAStech 员工失踪案，深度整合了信用卡交易数据、GPS 轨迹数据和员工信息档案。通过构建多维度可视化分析大屏，还原事件全貌，精准识别异常行为模式与高危可疑人员。

## 核心模块：联合查询系统 
该核心模块位于平台“任务求解”菜单下的“任务五”板块，专为重点调查对象的复杂线索剥离与时空重叠分析而设计。

**🛠️ 使用说明：**
1. **目标锁定**：在顶部控制面板中，按需选取特定的“调查日期”与“目标员工”（均支持多选及全选）。
2. **左侧空间视图**：
   - 真实地理底板上将动态渲染选定人员的 GPS 行驶路线与信用卡消费星标，并为不同嫌疑人分配专属色彩。
   - 系统已内置微量坐标偏移算法，当多人在同一地点消费时，星标会呈环形散开，彻底解决视觉遮挡问题。
   - 鼠标悬停即可查看精确的交易时间、地点及人员归属。
3. **右侧拓扑视图**：
   - **单人模式**：若仅查询单一员工，系统将自动深挖，呈现与该目标隐藏联系最紧密的 Top 10 核心关系网。
   - **多人模式**：若同时圈定多名目标，网络将智能聚焦，直观揭示该特定群体内部的隐秘交往闭环。

## 功能特点
- 员工动态轨迹与时空可视化
- 信用卡资金流向与异常交易检测
- 人员隐秘社交关系网络分析
- 全局自适应交互式筛选与多层级数据钻取
- 双视图融合的多目标动态比对引擎

## 技术栈
- Python 3.10+
- Dash & Dash Bootstrap Components
- Pandas & NumPy
- Plotly (NetworkX 支持拓扑计算)

## 运行方式
1. 安装依赖：`pip install -r requirements.txt`
2. 运行应用：`python app.py`
3. 打开浏览器访问：http://127.0.0.1:8050
